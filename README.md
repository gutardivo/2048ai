# 2048 AI

Just a little playground to get back into AI.

I'm building 2048 in Python and experimenting with genetic algorithms, heuristics, agents, and whatever else I feel like trying.

This repo is for learning. It's not a showcase, it's not production code, and it's definitely not meant to prove how good or bad anyone is at AI/software/anything.

Some code will probably suck.
Some ideas will probably be wrong.
Some experiments will probably go nowhere.

That's the point.

I'm here to learn by building, breaking shit, testing things, and figuring out why they work (or don't).

If you're here to learn too, cool, create your fork.

If you're here to judge the code as a representation of someone's actual ability, you're probably looking at the wrong repo.

Just a playground. Have fun!
